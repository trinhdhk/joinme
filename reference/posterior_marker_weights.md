# Posterior individual marker-weight alias

Posterior individual marker-weight alias

## Usage

``` r
posterior_marker_weights(object, ...)
```

## Arguments

- object:

  A fitted JoiNMe model.

- ...:

  Arguments forwarded to
  [`marker_weights()`](https://trinhdhk.github.io/joinme/reference/marker_weights.md).

## Value

The draw matrix returned by `marker_weights(summary = FALSE)`.
