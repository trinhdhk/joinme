# Posterior coefficient alias for fitted JoiNMe models

Posterior coefficient alias for fitted JoiNMe models

## Usage

``` r
posterior_coef(object, ...)
```

## Arguments

- object:

  A `JoiNMeFit` object.

- ...:

  Additional arguments forwarded to
  [`coef()`](https://rdrr.io/r/stats/coef.html).

## Value

The same object returned by `coef(object, summary = FALSE, ...)`.
