# The 'JoiNMe' package.

Joint Mixed-Effects (JoiNMe) Model for Multivariate Longitudinal and
Survival Data

## Details

Key entry points are
[`joinme()`](https://trinhdhk.github.io/joinme/reference/joinme.md) for
model fitting, [`predict()`](https://rdrr.io/r/stats/predict.html) for
dynamic prediction, and
[`plot()`](https://rdrr.io/r/graphics/plot.default.html) for
visualisation of predicted trajectories and survival curves.
